# Monitor groups

Monitor groups organize monitors within the currently selected workspace. They
are separate from **Groups and access**, which controls user membership and
permissions. A monitor can belong to more than one monitor group.

Create and edit groups in **Monitor groups** in the dashboard. Adding a monitor
to a group requires that both belong to the same active workspace. Monitor
groups do not change monitor schedules, notification channels, status-page
membership, or user access.

The authenticated API supports:

- `GET /api/v1/monitor-groups` — list groups in the active workspace.
- `POST /api/v1/monitor-groups` — create a group with `name`, optional
  `description`, and optional `monitor_ids`.
- `GET /api/v1/monitor-groups/{id}` — get a group and its monitor IDs.
- `PATCH /api/v1/monitor-groups/{id}` — update its name, description, or
  membership.
- `PUT /api/v1/monitor-groups/{id}/monitors` — replace its monitor IDs.
- `DELETE /api/v1/monitor-groups/{id}` — delete the group without deleting its
  monitors.
